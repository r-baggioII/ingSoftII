# 📘 Ingeniería de Software II  

Este repositorio contiene los trabajos, prácticas y proyectos desarrollados durante la cursada de la materia **Ingeniería de Software II**. El objetivo es aplicar conceptos avanzados de la ingeniería de software en el desarrollo de sistemas, utilizando metodologías y buenas prácticas.  

## 📂 Contenido del repositorio  

- → Informes y diagramas.  
- → Código fuente de los proyectos.  
- → Pruebas unitarias y de integración.   

## 🛠️ Tecnologías y herramientas  

- Lenguaje principal: **Java / HTML / CSS / SpringBoot / Bootstrap**    
- Metodología: **Scrum / RUP**    

## 🚀 Objetivos de la materia  

- Profundizar en el ciclo de vida del desarrollo de software.  
- Aplicar **metodologías ágiles** en proyectos reales.  
- Diseñar sistemas aplicando **arquitecturas de software**.  
- Implementar **buenas prácticas** de programación y testing.
