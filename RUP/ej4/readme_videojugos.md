
# Instrucciones para usar `videojuegos_ej4`

1. Crear la base de datos MySQL usando [este script SQL](./videojuegos.sql).
2. Cambiar el archivo `application.properties` y colocar el nombre de la base de datos, usuario y contraseña correspondientes.
3. Para ingresar a la app web: http://localhost:9000/inicio

---

## Script SQL para base de datos

El archivo [`videojuegos.sql`](./videojuegos.sql) contiene el script necesario para crear la base de datos y las tablas requeridas. Ejecútelo en su servidor MySQL antes de iniciar la aplicación.
