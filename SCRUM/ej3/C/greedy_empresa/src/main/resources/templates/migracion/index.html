Cargar Archivo de Migración

Seleccione un archivo de texto (.txt) con los datos de los proveedores.

Información

Formato del archivo:

Cada línea debe contener los datos de un proveedor separados por punto y coma (;):

NOMBRE;APELLIDO;TELEFONO;CORREO_ELECTRONICO;CUIT;CALLE;NUMERO;LOCALIDAD;DEPARTAMENTO;PROVINCIA;PAIS;CODIGO_POSTAL

Ejemplo:

Juan;Pérez;123456789;juan@email.com;20123456789;San Martín;123;Buenos Aires;Buenos Aires;Buenos Aires;Argentina;1000

Notas importantes:

  • Los campos nombre, apellido, correo electrónico y CUIT son obligatorios
  • El sistema busca la localidad por código postal y nombre
  • Si un proveedor ya existe (mismo CUIT), se omite
