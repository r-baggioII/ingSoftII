Si tienes errores de autenticación:

Para generar una contraseña de aplicación:

  1. Ve a Google Account Settings
  2. Seguridad → Autenticación de 2 factores → Contraseñas de aplicación
  3. Genera una nueva contraseña para "Otra aplicación personalizada"
  4. Usa esa contraseña en lugar de "Greedy123" en application.properties
