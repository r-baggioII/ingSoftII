# Opciones de software para venta de entradas de cine

## 1. **Ticketor**  
- Descripción: Software de venta de entradas para cines/múltiples salas que permite asignación de asiento, configuración de niveles de precio, cambios de precio según tiempo o evento.
- Precio: Plan estándar sin cuota mensual: 2,90 % + US$0,69 por entrada. 
- Link: [https://www.ticketor.com/](https://www.ticketor.com/)  

## 2. **Booklux**  
- Descripción: Sistema de reservas para salas/cines que permite gestionar salas, horarios, reservas online, aplicación cliente, también admite **precios dinámicos / “dynamic pricing”**.
- Precio: Plan gratuito (hall/sala): **€0/mes**. Plan “Plus”: **€11,99/mes + IVA por sala**. 
- Link: [https://www.booklux.com/en/cinema-booking-system](https://www.booklux.com/en/cinema-booking-system)  

## 3. **CINEsync**  
- Descripción: Solución completa de gestión de cine: ventas de entradas online, taquilla, concesión, múltiples salas, gestión de empleados, promociones, integración web/app.
- Precio: No aparece tarifa fija pública; requiere solicitar cotización personalizada.  
- Link: [https://www.cinesync.io/](https://www.cinesync.io/)
