# 3 opciones de software para colegios

1. **openSIS** — Sistema de información estudiantil para gestionar alumnos, grados, aulas, profesores y notas. *Open-source / edición comunitaria gratuita;* también ofrece ediciones y hosting de pago.  
   https://www.opensis.com/ 

2. **Gibbon** — Plataforma escolar flexible y open-source que centraliza matrícula, asistencia, calificaciones y gestión docente. *Gratuito (puedes alojarlo tú mismo).*  
   https://gibbonedu.org/ 

3. **Schoology (PowerSchool Schoology Learning)** — LMS/SIS usado en K-12 para cursos, entregas y calificaciones; tiene versión básica gratuita y planes empresariales de pago.  
   https://www.powerschool.com/solutions/personalized-learning/schoology-learning/
