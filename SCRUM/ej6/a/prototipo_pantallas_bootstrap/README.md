Prototipos de pantallas (HTML + Bootstrap)

Archivos:
- index.html: Dashboard con links a las pantallas.
- sucursal.html: Form para Sucursal y lista de cajas.
- caja.html: Vista de Caja con facturas asociadas y botón para generar reporte (simulado).
- factura_cliente.html: Form para crear una Factura al Cliente con detalles.
- factura_proveedor.html: Form para crear una Factura de Proveedor.
- cliente.html: Form y lista de facturas de un cliente.
- proveedor.html: Form y lista de facturas recibidas.
- producto.html: Form y listado de productos.

Abrir cualquiera de los archivos en un navegador para ver el prototipo. Los formularios son estáticos y sirven como maqueta visual.
