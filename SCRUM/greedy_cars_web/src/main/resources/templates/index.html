Características de la Arquitectura

Proyecto Web (Frontend - Puerto 8081)
  • Controladores MVC (@Controller)
  • Renderiza vistas HTML con Thymeleaf
  • Consume API REST mediante RestTemplate
  • Maneja la presentación y navegación
Proyecto API (Backend - Puerto 9000)
  • RestControllers (@RestController)
  • Expone endpoints REST (JSON)
  • Lógica de negocio y acceso a datos
  • Conectado a base de datos MariaDB
