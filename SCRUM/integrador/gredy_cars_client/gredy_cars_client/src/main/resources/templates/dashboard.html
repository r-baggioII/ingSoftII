Información del Sistema
  • Cliente: Aplicación Spring Boot MVC con Thymeleaf
  • Backend API: http://localhost:18082/greedy_cars/api
  • Autenticación: JWT en cookies HttpOnly
  • Protección de rutas: AuthCheckInterceptor + Backend verification
Cómo funciona
  1. El usuario se autentica en /login
  2. El controlador MVC envía las credenciales al backend
  3. El backend valida y devuelve un JWT en cookie HttpOnly (Set-Cookie)
  4. El cliente copia el header Set-Cookie al response para que el navegador guarde la cookie
  5. Para cada ruta protegida, el AuthCheckInterceptor valida la cookie con el backend
  6. Los servicios del cliente copian la cookie en cada petición al backend
